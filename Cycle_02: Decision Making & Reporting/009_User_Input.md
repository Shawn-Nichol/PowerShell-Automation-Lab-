# 🛡️ User Input with Read-Host


## 📌 Executive Summary

This lesson introduced interactive PowerShell scripts using Read-Host. User input allows scripts to accept investigation targets at runtime instead of relying on hard-coded values.


## 🎯 Learning Objective

Learn how to collect user input and store it in variables that can be used throughout a PowerShell script.

## 🔐 Cybersecurity Application

Security analysts frequently investigate different processes, services, users, and systems. Read-Host enables investigators to reuse the same script while supplying different targets for each investigation.
