# 🛡️ PowerShell for Cybersecurity

This repository documents my structured PowerShell learning journey with a focus on cybersecurity investigations, threat hunting, incident response, and security automation.

The goal of this project is to develop practical PowerShell skills that can be applied to:

- Security Operations Center (SOC) investigations
- Windows host analysis
- Threat hunting
- Incident response
- Evidence collection
- Detection engineering
- Security automation

Each lesson introduces a new PowerShell concept and demonstrates how it can be applied to real-world cybersecurity scenarios. Every five lessons conclude with an investigation challenge that reinforces the concepts learned throughout the cycle.

---

# 🎯 Objectives

Through this project I am working toward the ability to:

- Investigate Windows processes and services
- Analyze large datasets efficiently
- Collect and review forensic evidence
- Review user, service, and system activity
- Investigate indicators of compromise (IOCs)
- Automate repetitive investigation tasks
- Develop reusable security tools
- Perform host-based security investigations
- Support threat hunting and incident response activities
